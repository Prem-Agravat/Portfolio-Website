# 💼 Prem Agravat - Personal Portfolio Website

🔗 **Live Link:** [premagravat.netlify.app](https://premagravat.netlify.app/)

A modern, responsive, and interactive personal portfolio website showcasing my skills, projects, education, and internship experience. 

Built using HTML5, CSS3, JavaScript, jQuery, and Isotope filtering, with FormSubmit integration for direct contact form submissions.

## 📌 Tech Stack
- **Languages:** HTML5, CSS3, JavaScript, Dart
- **Frameworks & Libraries:** Flutter, Bootstrap, jQuery, Isotope (for project filtering), Typed.js (for typing animations), Vanilla-Tilt.js (for 3D card tilt effects)
- **Database & Tools:** PostgreSQL, MySQL, Firebase, Git & GitHub, Android Studio, VS Code, Figma

## 📂 Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **Dynamic Projects & Skills:** Loads projects and skills dynamically via JSON configurations (`projects.json` & `skills.json`).
- **Interactive Animations:** Features typed animations, interactive particles background, and 3D hover tilt effects.
- **Contact Form:** Integrated with FormSubmit to receive contact messages directly via email.
